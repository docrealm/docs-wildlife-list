# 动物保护名录

## 重点保护野生动物

- 国家重点保护野生动物名录（1989版）
    > [:link: 国务院公报](https://www.gov.cn/gongbao/content/2003/content_62289.htm)
    > （一九八八年十二月十日国务院国函[1988]144号关于《国家重点保护野生动物名录》的批复批准，一九八九年一月十四日中华人民共和国林业部、农业部令第1号发布，自一九八九年一月十四日施行）

- 《国家重点保护野生动物名录》（2003年2月调整）
    > - 2003年2月21日，[:link: 国家林业局令（第7号）](https://www.gov.cn/gongbao/content/2003/content_62289.htm)
    >
    > 麝科麝属（Moschus spp.）所有种，由国家二级调整为国家一级。

- 《国家重点保护野生动物名录》（2020年6月调整）
    > 2020年6月3日，[:link: 国家林业和草原局公告（2020年第12号）](https://www.forestry.gov.cn/main/3457/20200619/092010699781014.html)
    > 穿山甲属所有种（Manis spp.）所有种，由国家二级调整为国家一级。

- 国家重点保护野生动物名录（2021版）
    > - 2021年2月1日，[:link: 国家林业和草原局 农业农村部公告（2021年第3号）](https://www.forestry.gov.cn/main/3457/20210205/122612568723707.html)
    >
    > 名录共计收纳了980种和8类，包括国家一级保护动物234种和1类和国家二级保护动物746种和7类。
    > 其中，686种为陆生野生动物，由林业和草原局负责管理，294种和8类为水生野生动物由农业农村部负责。
